# 선배 특강 번역 작업 폴더

화면에 나가는 것은 `src/content/lectures/<특강>/<언어>.json` 이다.
이 폴더는 **그 JSON 을 만드는 원재료**다. JSON 을 손으로 고치지 말고 여기서 고쳐 다시 굽는다.

## 왜 JSON 을 직접 안 고치나

본문이 한 편에 1만 자가 넘고, 그것이 7개 언어로 존재한다. JSON 을 손으로 만지면
「챕터 하나가 통째로 빠졌다」·「영상 ID 가 번역돼 버렸다」·「표의 행 수가 언어마다 다르다」
같은 사고가 **아무도 모르게** 난다. 그래서 규칙을 하나로 못박았다.

> **구조는 언제나 `ko.json` 에서 복사한다. 번역은 «문자열 배열» 로만 주고받는다.**

번역이 어색할 수는 있어도 **화면이 깨질 수는 없다.**

## 파일

| 파일 | 무엇 |
|---|---|
| `choijunhyeok.ko.txt` · `osihye.ko.txt` | 한국어 원문 추출본(기준). **직접 고치지 말 것** — `ko.json` 에서 다시 뽑힌다 |
| `<특강>.<언어>.txt` | 번역본. 한 줄이 `번호<탭>문자열` |

번호는 한국어 추출본의 번호 그대로다. 번호를 달아 두었기 때문에
**몇 조각으로 나눠 써도 제자리를 찾고, 빠진 줄·중복을 정확히 집어낸다.**
문자열 안에서 줄을 바꿔야 하면 `\n` 으로 적는다(실제 개행은 줄 구분자라 쓸 수 없다).

## 쓰는 법

```bash
# ① 한국어 원문이 바뀌었을 때 — 추출본 다시 뽑기
python scripts/특강_번역_도구.py extract

# ② 번역 txt 를 고친 뒤 — JSON 다시 굽기
python scripts/특강_번역_도구.py inflate osihye th

# ③ 전 언어 구조·개수 점검 (커밋 전 필수)
python scripts/특강_번역_도구.py check
```

`check` 는 언어마다 **구조 일치 / 문자열 개수 / 빈칸 / 한국어와 그대로인 줄 수**를 찍는다.
「한국어와 동일」로 잡히는 몇 줄은 `ALUMNI PLAYBOOK`·`CUIF 2022` 같은 고유명이라 정상이다.

## 번역하지 않는 자리

`lang` · `slug` · `sourceUrl` · `video` · `no` · `id` · 블록 타입 `t` · `contact.value`(이메일).
도구가 애초에 뽑지 않으므로 신경 쓸 일이 없다.

## 한국어 원문을 고쳐야 한다면

`src/content/lectures/<특강>/ko.json` 을 고치고 → `extract` → **바뀐 번호 줄만** 각 언어 txt 에서
고쳐 → `inflate` → `check`. 줄이 늘거나 줄면 번호가 밀리므로, 문구만 바꾸는 편이 안전하다.

## 번역 품질에 대하여

한국어 외 6개 언어는 **기계 번역**이다. 화면에도 그렇게 적어 두었고, 원문 링크도 함께 건다.
학생이 「뜻이 이상하다」고 하면 해당 번호 줄만 고쳐서 `inflate` 하면 된다 — 다른 언어는 손대지 않는다.
